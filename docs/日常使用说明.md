# Codex 实时语音“小欧”门控日常使用说明

## 开始实时语音

1. 先确认没有其他 Codex 任务正在运行；当前版本只验证单任务场景。
2. 双击项目根目录的 `启动Codex实时语音小欧门控.cmd`。
3. 等终端显示“状态：未唤醒”。
4. 打开 Codex 设置 → 常规 → 麦克风。
5. 临时选择 `CABLE Output (VB-Audio Virtual Cable)`，不要选择 `CABLE Input`。
6. 启动 Codex 实时语音。
7. 默认状态不会把可辨识人声送给 Codex；说“小欧”后停顿约两秒，再正常讲话。
8. 说“结束”后恢复静音；需要再次讲话时可重新说“小欧”。

## 结束实时语音

1. 先在实时语音中说“结束”。
2. 退出 Codex 实时语音。
3. 在门控终端按 `Ctrl+C`，确认终端显示虚拟输出恢复静音。
4. 回到 Codex 设置 → 常规 → 麦克风，恢复为“系统默认”。
5. 终端会停住并提醒恢复；确认完成后再按任意键关闭窗口。

## 使用边界

- Windows 默认麦克风和其他应用的录音设置不会被这个工具修改。
- Codex 当前把实时语音和听写共用同一个麦克风偏好；选择虚拟麦期间不要使用听写。
- Codex 的选择是客户端级，不是按任务保存；其他 Codex 任务的实时语音也会经过门控。
- 其他 Codex 任务同时运行时，客户端可能发生实时语音会话状态或事件路由冲突；本工具无法修复该客户端内部问题。
- 程序未运行时，`CABLE Output` 没有可辨识语音；如果忘记恢复 Codex 设置，语音输入
  可能表现为没有声音，此时选择“系统默认”即可。
- 程序只在本机识别“小欧”和“结束”，不保存录音或连续转写。

## 故障处理

- 终端提示找不到模型或 Python：不要继续实时语音，把终端截图发给 Codex。
- 终端提示虚拟音频预检失败：先保持 Codex 为“系统默认”，不要选择其他 CABLE 设备。
- 出现识别异常、队列溢出或音频设备错误时，程序会安全静音并退出。
- 任何异常结束后，都先把 Codex 麦克风恢复为“系统默认”。
