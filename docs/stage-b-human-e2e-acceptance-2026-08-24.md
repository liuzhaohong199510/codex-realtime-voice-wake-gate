# 阶段 B Codex 实时语音端到端真人验收回执

日期：2026-08-24

客户端：OpenAI Codex Desktop `26.818.5229.0`

门控规则：“小欧”放行，“结束”静音。

## 验收环境

- Windows 默认输入：本机数字麦克风。
- Windows 默认输出：本机扬声器。
- 本地桥输入：本机数字麦克风，`16 kHz` 单声道 PCM16。
- 本地桥输出：`CABLE Input` 的 Windows WASAPI 端点，`48 kHz` 单声道 PCM16。
- Codex 验收期间临时选择：`CABLE Output (VB-Audio Virtual Cable)`。
- 验收结束后 Codex 麦克风已恢复为“系统默认”。

## 真人端到端结果

1. **未唤醒静音：通过。** 用户在未说“小欧”时说“请回答数字六”，Codex 无反应。
2. **唤醒后放行：通过。** 用户说“小欧”后再要求只回答数字七，Codex回答“七”；
   本地桥同时输出“已唤醒，正在放行”。
3. **结束后静音：通过。** 用户说“结束”后再说“请回答数字八”，Codex 无反应；
   本地桥同时输出“已结束，恢复静音”。
4. **退出安全：通过。** 本地桥停止后输出“虚拟输出恢复静音”，没有继续占用音频流。
5. **设置回退：通过。** 用户提供 Codex 常规设置截图，麦克风显示为“系统默认”。

## 结论

在当前电脑、当前客户端版本和已接受的临时切换边界内，小欧门控完成了 Codex 实时
语音端到端验证：默认静音、唤醒后连续放行、结束后重新静音、退出后关闭虚拟输出。

## 证据边界

- 真人结果来自用户在当前 Codex 实时语音中的实际口述和响应。
- 本地程序不保存音频、不输出连续转写；放行状态下的语音会按实时语音功能送给 Codex。
- 当前 Codex 的实时语音与听写共用麦克风偏好，因此临时选择虚拟麦期间不要使用听写。
- 此回执不证明休眠恢复、设备热插拔、长时间运行或未来客户端版本仍然兼容。
