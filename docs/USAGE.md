# 使用指南

## 每次使用前

确认以下条件：

- Windows 默认输入仍是真实麦克风。
- Windows 默认输出仍是常用扬声器或耳机。
- Codex 麦克风目前为“系统默认”。
- 没有另一个门控进程占用麦克风或 VB-CABLE。

## 标准使用流程

### 1. 启动门控

双击项目根目录：

```text
启动Codex实时语音小欧门控.cmd
```

成功时会显示真实麦克风和虚拟输出设备，并进入：

```text
状态：未唤醒。说“小欧”开始，说“结束”关闭。
```

此时 `CABLE Output` 应只有静音。

### 2. 临时切换 Codex 麦克风

打开 Codex 设置：

1. 进入“常规”。
2. 找到“麦克风（用于语音聊天和听写）”。
3. 选择 `CABLE Output (VB-Audio Virtual Cable)`。

不要修改 Windows 系统默认麦克风。其他应用仍可继续使用真实麦克风。

### 3. 开始实时语音

进入 Codex 实时语音后：

1. 先说“小欧”。
2. 终端显示“已唤醒，正在放行”后开始连续对话。
3. 准备停止时说“结束”。
4. 确认终端显示“已结束，恢复静音”。

### 4. 安全退出

1. 先说“结束”。
2. 退出 Codex 实时语音。
3. 在门控窗口按 `Ctrl+C`。
4. 回到 Codex 设置，把麦克风恢复为“系统默认”。
5. 看到启动脚本提示后按任意键关闭窗口。

## 状态含义

| 终端提示 | 含义 | 建议动作 |
|---|---|---|
| 未唤醒 | 输出静音 | 说“小欧” |
| 已唤醒，正在放行 | 真实语音进入虚拟麦 | 可以对话 |
| 已结束，恢复静音 | 输出再次静音 | 可退出会话 |
| 音频桥异常，已安全静音 | 发生设备或缓冲错误 | 停止程序并排错 |
| 门控已停止 | 音频流已关闭 | 恢复 Codex 系统默认麦克风 |

## 只测试关键词检测

如果不想连接 VB-CABLE 或 Codex，可双击：

```text
启动小欧门控原型.cmd
```

此入口只验证本地关键词状态，不把语音路由到虚拟麦克风。

## 真人验收入口

双击：

```text
验收小欧门控原型.cmd
```

程序逐组提示测试场景。每组只有按 Enter 后才打开麦克风；输入 `q` 可以在开麦前退出。验收不保存录音，也不输出全文转写。

## 重要限制

Codex 当前对实时语音和听写使用同一个麦克风偏好。选择 `CABLE Output` 期间，普通听写也会经过门控；完成实时语音后必须恢复“系统默认”。

此工具不能判断你正在和谁说话。门控打开后，进入真实麦克风的全部声音都有可能被放行，所以离开电脑或与他人交谈前应先说“结束”。
