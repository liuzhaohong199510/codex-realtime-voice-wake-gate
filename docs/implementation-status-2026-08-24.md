# Codex 实时语音“小欧”门控实施状态

日期：2026-08-24

## 已验证完成

- 默认关闭、“小欧”开启、“结束”关闭的本地状态机。
- Vosk 本地中文控制词识别与异常安全关闭。
- 延迟音频门控核心：唤醒词、结束词和识别异常对应的缓冲音频不会被下游释放。
- VB-CABLE 播放端只读预检：只接受唯一的 `CABLE Input`，不会回退系统默认输出。
- 当前电脑实机预检返回 `missing`；检查前后默认设备索引均为输入 `1`、输出 `3`。
- 预检过程只枚举设备和检查格式，没有打开音频流、录音、安装驱动或修改系统设置。
- 十组真人验收程序已实现：用户逐组确认后才临时开麦，只保留内存音频并输出事件/状态报告。

## 已实现但尚未实机联调

- 识别结果到门控 PCM 输出的本地路由核心已经实现并由自动测试覆盖。
- 十组验收规则、固定窗口采样和交互入口已经由自动测试覆盖，但尚未由用户实际口述验收。
- 因未安装 VB-CABLE，尚未把输出连接到真实虚拟音频端点。

## 第一次真人验收结果

- 结果：`6/10`，未通过，因此没有进入驱动联调。
- 主失败 1：说“小陈”时被受限词表误识别为“小欧”，门控误开。
- 连锁失败：后续“小欧”组因上一组误开而初始状态错误。
- 主失败 2：连续普通讲话被误识别为“结束”，门控误关。
- 连锁失败：后续重复“小欧”组因上一组误关而初始状态错误。
- 修复方向：取消极小受限词表，改用完整中文词表；局部结果不触发；最终控制词需达到
  `0.65` 最低置信度。该修复仍需第二次真人十组验收确认。
