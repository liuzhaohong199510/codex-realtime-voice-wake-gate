# v0.1.0：首个公开原型

这是 Codex 实时语音“小欧”唤醒门控的首个公开原型版本。

## 核心能力

- 默认向虚拟麦克风输出静音。
- 本地识别“小欧”后持续放行语音。
- 本地识别“结束”后恢复静音。
- 通过短时延迟缓冲抑制控制词进入下游。
- 把真实麦克风 16 kHz 音频路由到 VB-CABLE 48 kHz 端点。
- 设备缺失、重复、格式错误或运行异常时失败关闭。
- 不保存录音、不生成全文转写、不上传运行时遥测。

## 验证

- 74 项自动化测试通过。
- Windows 11、Python 3.11、Codex Desktop `26.818.5229.0` 完成真人端到端验收。
- 验收覆盖未唤醒无响应、唤醒后放行、结束后恢复静音。

## 安装前必读

- 需要独立安装 VB-CABLE，并在安装后重启 Windows。
- 需要从 sherpa-onnx 官方 Release 自行下载 KWS 模型。
- 当前模型权重许可尚不明确，本 Release 不包含模型文件。
- VB-CABLE 是第三方 Donationware，本 Release 不包含驱动安装包。
- 当前 Codex 的实时语音和听写共用麦克风设置；使用期间临时选择 `CABLE Output`，结束后必须恢复“系统默认”。
